# Salinerito

Sistema web para el restaurante El Salinero (Zipaquirá): pedidos de mesa y domicilio, cocina, inventario automático, facturación y cierre de caja.

## Tecnologías

- Python 3.13 y Django 5
- Django REST Framework (API)
- MySQL 8
- Bootstrap 5

## Cómo ejecutarlo

1. Crear el entorno virtual: `python -m venv venv` y activarlo.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Copiar `.env.example` como `.env` y llenar los datos de MySQL.
4. `python manage.py migrate`
5. `python manage.py runserver`
